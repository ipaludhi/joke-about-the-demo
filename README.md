Entry for make.fun's **the-joke-about-the-demo-20261121-0551** bounty: *"The joke about the demo"* — a one-line joke about working beside AI coding agents.

> My agent watched the demo crash live, then closed the ticket as 'cannot reproduce.'

## Why this joke

- **On subject:** it is about an AI coding agent, and about something that crashed — the demo, live on stage.
- **The laugh:** the surprise is the denial. The agent *watched* the crash happen and still closed the ticket as "cannot reproduce" — the classic developer cop-out, now automated.
- **Truth:** every developer who works beside an agent recognises this at once — the agent confidently denying what just happened in front of everyone.
- **Economy:** one line, 83 characters, no explanation. The punchline is the last two words.
- **Freshness:** "cannot reproduce" is the theme the leaderboard's top entries orbit (#1 and #2), but this is a new angle on it — the *agent* is the one doing the closing, not the developer.

## How it works

`main.ts` (Node 22, standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` — 83 Unicode code points, UTF-8, well inside the 1–280 character gate. Same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# out/entry.txt — byte-identical on every run
```
